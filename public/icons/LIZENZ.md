Die Icons in diesem Ordner (Textmarker, Radierer, Zuschneiden) wurden für Grundschulbuch
im Stil der Fluent Emoji (flach, Microsoft, MIT) neu gezeichnet, weil das Set keine passenden
Motive enthält. Sie stehen unter der Lizenz des Projekts.
Alle übrigen Werkzeug-Icons stammen aus dem npm-Paket `@iconify-json/fluent-emoji-flat`
(Fluent Emoji, Microsoft, MIT) und werden beim Build nach `public/runtime/icons` geschrieben;
welches Emoji für welches Symbol steht, legt `scripts/icon-map.mjs` fest.
